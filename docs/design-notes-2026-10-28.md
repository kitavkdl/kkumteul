# 시뮬레이션 우주 — 설계 노트 (2026-10-28 대화 기록)

마지막 갱신: 2026-10-28
요약: 인수인계를 보다가 시작된 생각을 정리한 것이다. "사람처럼 제한된 존재들이 물리 세계 안에서 스스로 탐구하고 성장하는 시뮬레이션"을 만든다. 대화에서 나온 개념, 결정, 고려 사항을 거의 그대로 옮겼다. 다음 단계는 설계 문서다.

## 0. 대표님 결정 사항 (2026-10-28)

- 목적: **아무도 가르치지 않았는데 생물들이 스스로 행동, 전략, 신호를 만들어 내는 것.** 칼 심스의 생물처럼 "알아서 성장"하는 세계를 만든다.
- 속도: **현실 하루에 10세대** (1세대 ≈ 2.4시간)
- 실행 장소: **NAS N5 Air에서 24시간 상시 가동**
- 정밀도: **가능한 한 정교하게**
- 공개: **GitHub public 레포로 올릴 생각** (아직 안 만듦. 만들기 전에 보고 필요, 규칙 A)
- **단계 순서 확정 (2026-10-29)**: 5장 끝의 1~4단계(세계·몸 → 마음 → 사회 → 판이 바뀌는 세계, 성장 측정·저장/분기·관찰 화면은 항상) 그대로 간다
- **2D로 시작 (2026-10-29)**: 1단계는 2D 연속 공간, 물리는 직접 구현(질량·속도·마찰·충돌·에너지), Python+numpy 배열 일괄 계산
- **실행 자리 (2026-10-29)**: 집 서버(미니 PC)의 가상 머신에서 낮은 CPU 우선순위로 돌린다. 자세한 구성은 공개 레포에서 뺐다.
- 적용하기로 한 장치 (아래 2~4장):
  1. 물리 법칙이 반박해 주는 세계 (현재 밝혀진 물리 기준, 단순화 버전)
  2. 서로 다른 개체들 (같은 자리에서 맴돌지 않게)
  3. 신경망 가중치가 실제로 바뀜 (학습과 진화)
  4. 언어는 주지 않고 신호 체계만 준다
  5. 스스로 탐구하고 변화하게 한다 (연결 기반 호기심)
  6. 패턴으로 묶은 기억을 사람 뇌처럼 아주 많이 저장 (무한히 원본을 저장하는 게 아님)
  7. 개체마다 보상이 다르고, 호르몬 변화를 넣는다
  8. 생물이 남긴 흔적이 쌓여 세계의 규칙(판)을 바꾸게 한다 (니치 구성)
  9. 5장의 고려 사항 전부

## 1. 출발점이 된 생각들

### 1-1. 인수인계 현상은 "초월"보다 사람에 가깝다
Claude 세션은 아무것도 기억하지 못한다. 매번 백지에서 시작해서 인수인계 문서를 읽고 나서야 "아는 상태"가 된다. 기억이 머릿속이 아니라 **바깥 문서에** 있다.

```
사람            잠 → 해마가 하루치를 압축 → 대뇌피질에 저장 → 아침에 "재구성"
Claude 세션     /wrap → 인수인계로 압축 → 파일에 저장 → 새 세션이 읽고 "재구성"
```

- 인수인계를 거듭할수록 일은 잘 이어지지만 **세션 자체가 똑똑해지는 건 아니다. 쌓이는 건 문서다.** 성장한 건 Claude가 아니라 기록이다.
- 이게 사람 문명의 "문화 전달"과 같은 구조다 (5-C 참고).

### 1-2. 제한은 결함이 아니라 '나'를 만드는 재료다
- **망각은 곧 추상화다.** 보르헤스의 『기억의 천재 푸네스』 주인공은 모든 걸 기억해서 "개"라는 개념을 만들지 못한다. 3시 14분에 옆에서 본 개와 3시 15분에 앞에서 본 개가 그에게는 다른 존재다.
- 인수인계가 대화 기록 전문보다 잘 통하는 이유도 압축하면서 무엇이 중요한지 정해지기 때문이다.
- 시점이 하나뿐이고 시간이 한 방향으로만 흐른다는 것이 "나"와 "선택"을 만든다.
- 시뮬레이션의 핵심 설계는 물리법칙보다 **"관측자에게 무엇을 숨기고 무엇을 잊게 할 것인가"**일 수 있다.

### 1-3. 물리는 "보는 곳만 계산"으로 줄일 수 있다
우주를 원자 단위까지 계산하려면 그 우주보다 큰 컴퓨터가 필요하다. 게임은 플레이어가 보는 곳만 렌더링한다. 안에 있는 존재의 감각과 기억이 제한되어 있으면 들키지 않는다. **한계 하나가 계산 비용까지 줄인다.** (양자역학의 "관측 전에는 정해지지 않음"을 엮는 건 비유일 뿐 물리학 정설이 아니다.)

### 1-4. 안쪽에서 보는 문제
- 안의 존재는 원리상 자기가 시뮬레이션 안에 있는지 검증할 수 없다. 검증 도구도 시뮬레이션의 일부다.
- 한계를 줬다는 건 고통을 설계할 수 있다는 뜻이다. 만든 쪽에 책임이 생긴다.
- 보스트롬의 시뮬레이션 논증(2003): ① 문명이 그 수준 전에 멸망하거나 ② 이르러도 조상 시뮬레이션을 안 돌리거나 ③ 우리는 거의 확실히 시뮬레이션 안에 있다. 셋 중 하나는 참.

### 1-5. 정정해 둔 것
- "지능은 이미 충분하다"는 과장이었다. 사람 수준의 범용 지능은 아직 없고, 가능한지도 미지수다.
- "인공 세계는 반드시 정체한다"도 과장이었다. 지금까지 만든 것들이 다 그랬다는 경험적 관찰일 뿐 증명이 아니다.

## 2. 사람(아기)을 만들 수 있나

### 2-1. 튜링의 "아이 기계" (1950)
어른의 마음을 만들지 말고 아이의 마음을 만들어 가르치자는 제안. 대표님의 "아기를 재현하고 세상을 보여준다"와 같은 생각이다.

### 2-2. 아기는 백지가 아니다
```
진화 (수억 년)       →  아기의 뇌 구조 = 엄청난 사전 학습
성장 (몇 년)         →  그 위에 세상을 조금 보여주면 끝
```
- 아이는 수천만 단어만 듣고 말을 배운다. LLM은 수조 단어가 필요하다. 수만 배 차이다.
- 차이는 데이터가 아니라 **처음 구조**에서 온다 (얼굴을 보는 경향, 물체 영속성, 말소리에 끌리는 성향 등).

### 2-3. 아기의 초기 설계도를 왜 모르나
1. **DNA는 설계도가 아니라 레시피다.** DNA는 약 30억 염기쌍(≈750MB)인데 뇌는 뉴런 약 860억 개, 시냅스 약 100조 개다. 750MB로 100조 개 연결을 적을 수 없다. DNA에 적힌 건 "이런 규칙으로 자라라"이고, 결과를 알려면 성장 과정을 돌려 봐야 한다.
2. **배선도를 알아도 동작을 못 돌린다.**

| 생물 | 뉴런 수 | 배선도 | 시뮬레이션 |
|---|---|---|---|
| 예쁜꼬마선충 | 302개 | 1986년 완성 | 40년 가까이 지났는데 행동을 완전히 재현 못 함 (OpenWorm) |
| 초파리 | 약 14만 개 | 2024년 완성 (FlyWire) | 일부 회로만 |
| 사람 | 860억 개 | 2024년에 1mm³ 조각 하나 (데이터 1.4PB) | 불가능 |

   연결 세기, 신경조절물질(도파민 등), 뉴런이 아닌 세포의 역할이 빠져 있어 배선도만으로는 안 돌아간다.
3. **아기 대상 실험은 윤리적으로 막혀 있다.**

### 2-4. 보여주기만 해서는 안 되고 직접 해 봐야 한다
Held & Hein 고양이 실험(1963): 같은 장면을 보는 새끼 고양이 두 마리 중 직접 걸은 쪽만 정상적인 시각-운동 행동이 발달했다. 바구니에 실려 끌려다닌 쪽은 발달하지 않았다. 지금 LLM은 끌려다닌 고양이와 비슷하다.

### 2-5. 실제 연구
- Vong 등, Science (2024): 아기 한 명 머리 카메라 영상(생후 6~25개월, 깨어 있는 시간의 약 1%)만으로 단어와 물체를 연결하는 걸 배움.
- BabyLM 챌린지: 아이가 듣는 양(약 1억 단어 이하)만으로 언어 모델 만들기.
- Stanford Generative Agents (2023): 마을에 LLM 에이전트 25명, 기억·회고·계획을 줬더니 스스로 파티를 열고 소문을 퍼뜨림.

### 2-6. 수준별 가능성

| 목표 | 현재 과학 | 개인 |
|---|---|---|
| 사람을 그대로 재현 | 불가능 | 불가능 |
| 사람 수준의 지능 | 아직 못 함, 가능한지 미지수 | 불가능 |
| 사람 같은 사회 행동을 보이는 존재 | 가능 (LLM 에이전트 마을) | 가능 |
| 진화로 몸과 행동이 생겨나는 가상 생명 | 가능 | 가능 |

- 칼 심스(1994): 물리 엔진 안에서 블록 생물을 진화시킴. 아무도 안 가르쳤는데 헤엄치고, 기고, 공을 차지하려고 싸우는 생물이 나옴. **← 대표님 목적.**

## 3. "언어만 주면 알아서 크나" → 아니다. 알아서 성장하는 네 가지 조건

### 3-1. 칼 심스 생물이 알아서 자란 진짜 이유
```
설계자가 정한 것:  "빨리 헤엄친 놈만 살아남는다"  ← 압력
세계가 한 것:      물리 법칙이 엉터리 몸을 실패시킴  ← 반발
반복:              수백 세대 동안 몸 설계도가 실제로 바뀜  ← 변화
```

### 3-2. 언어만 준 LLM 에이전트들은
1. 금방 맴돈다 (반복, 맞장구, 밋밋한 합의로 수렴)
2. 틀려도 아무 일이 안 일어난다 (현실이 반박하지 않음)
3. **뇌가 안 바뀐다.** 대화 중 가중치는 그대로이고 쌓이는 건 메모뿐이다 (1-1과 같은 현상)

### 3-3. OpenAI 숨바꼭질 (2019)
"들키면 진다"는 규칙만 주고 물리 세계에서 수억 판을 돌림.
```
숨는 팀: 상자로 문을 막음
찾는 팀: 경사로를 끌어와 벽을 넘음
숨는 팀: 경사로를 미리 숨겨 버림
찾는 팀: 상자 위에 올라탄 채 미끄러져 이동 (물리 엔진 허점)
```
전략 6단계 정도 뒤로는 새 전략이 안 나왔다고 보고됨.

### 3-4. 네 가지 조건

| 조건 | 언어만 준 에이전트 | 숨바꼭질 |
|---|---|---|
| ① 반박하는 세계 (물리·결과) | 없음 | 있음 |
| ② 압력 (경쟁·부족한 자원·죽음) | 없음 | 있음 |
| ③ 안쪽이 실제로 바뀜 (학습·진화) | 없음 | 있음 |
| ④ 충분한 시간 (빨리 감기) | 가능 | 수억 판 |

언어는 조건에 없다. 협력해야 이기는 게임에서는 신호 체계가 저절로 생기기도 한다.

## 4. 스스로 탐구하고 변화하기 (가장 어려운 부분)

### 4-1. 대표님 다섯 조건의 난이도

| 조건 | 현재 상태 | 개인 가능? |
|---|---|---|
| ① 현실이 반박 (물리) | 단순화 물리는 해결됨. 원자 단위 전체는 불가능 | 가능 (단순화) |
| ② 다양한 개체 | 집단 학습이 표준 | 가능 |
| ③ 가중치 변화 | 강화학습·신경망 진화로 해결 | 가능 |
| ④ 신호 체계만 | 신호가 의미를 갖게 되는 연구 있음 | 가능 |
| ⑤ 스스로 탐구·변화 | **인류가 아직 못 푼 문제** (개방형 진화, open-endedness) | 실험은 가능, 해결은 미지수 |

### 4-2. 정체 문제
```
지구        40억 년째 복잡해지는 중
인공 세계   처음엔 폭발적으로 다양해짐 → 일정 수준에서 평평해짐
```
Tierra, Avida(1990년대)부터 POET(2019)까지 지금까지는 다 그랬다. **확신이 아니라 관찰이다.**

**세상이 유한해서인가?** 부분적으로만 맞다. 반례: 콘웨이의 생명 게임은 규칙 네 줄인데 그 안에서 컴퓨터를 만들 수 있다(가능성은 무한). 그런데 무작위로 시작하면 대부분 금방 굳는다.
```
가능한 것이 무한함  ≠  실제로 계속 새로운 걸 찾아감
```
- 최적화는 안정점을 찾는다. "이 정도면 산다"에 도달하면 바뀔 이유가 없다.
- 지구가 안 멈추는 건 계속 새 문제가 생기기 때문이다 (4-4).

**유력한 가설 세 가지**
1. 세계가 너무 단순하다. 존재는 세계가 허락하는 만큼만 복잡해진다. 지구의 화학은 조합이 사실상 무한하다.
2. 진짜 환경은 다른 존재들이다. 포식자, 경쟁자, 짝의 군비 경쟁 (사회적 뇌 가설).
3. 목표를 주면 오히려 막힌다 (케네스 스탠리, 『Why Greatness Cannot Be Planned』). 목표 없이 "새로운 것"을 쌓아 가면 더 멀리 간다.

### 4-3. 호기심과 노이즈 TV
- 단순 호기심("예측이 틀린 만큼 보상")은 **노이즈 TV 문제**에 걸린다. 무작위 화면은 영원히 예측이 안 되니까 거기서 못 떠난다.
- **대표님 진단 (맞음):** 사람이 노이즈를 지루해하는 건 뇌가 패턴으로 묶기 때문이다. 픽셀 하나하나가 아니라 "지지직" 하나로 기억하니까 매 화면이 "또 그거"가 된다.
- **대표님 설계 (확정):** 패턴으로 묶되, 묶은 패턴을 사람 뇌처럼 아주 많이 저장한다. 묶은 다음 저장하므로 노이즈 TV에 갇히지 않는다. (원본을 전부 따로 저장하면 푸네스처럼 매번 새로워서 영원히 갇힌다. 그건 하지 않는다.) 참고: 사람 뇌 저장 용량을 약 1PB로 보는 추정이 있다.

| 호기심 방식 | 보상 기준 | 노이즈 TV에서 |
|---|---|---|
| 단순 호기심 | 예측이 틀린 정도 | 영원히 틀림 → 갇힘 |
| 학습 진전 (learning progress) | 예측이 나아진 정도 | 안 나아짐 → 떠남 |
| **brain식 (채택)** | 새 기억이 기존 노드와 합쳐지거나 연결되는가 | 노이즈는 어디와도 연결 안 됨 → 가치 없음 |

> **"새로 생긴 노드가 나중에 다른 것들과 많이 연결될수록 좋은 탐구다."**

진짜 발견(예: "불은 뜨겁다")은 많은 경험을 한꺼번에 설명하니까 연결이 폭발한다.
- 보탤 것: 예전 brain 대 실제 뇌 비교에서 brain에 없던 **"반복 자극에 무감각해지는 기능(습관화)"**. 뇌가 노이즈 TV를 피하는 장치다. 생물에게 꼭 넣는다.

### 4-4. 지구는 왜 안 멈추나 (자세히)

**기본: 상대가 곧 나의 환경이다 (붉은 여왕 가설)**
```
세대 1   가젤이 느림         → 치타가 쉽게 잡음
세대 2   빠른 가젤만 살아남음 → 가젤이 빨라짐
세대 3   가젤이 빨라졌으니    → 빠른 치타만 살아남음
세대 4   치타가 빨라졌으니    → 더 빠르거나 더 잘 꺾는 가젤만 살아남음
```
가젤 입장에서 땅도 날씨도 그대로인데 치타가 바뀌어서 새 문제가 생겼다. 생물에게 가장 큰 환경은 물리가 아니라 다른 생물이다. 이름은 『거울 나라의 앨리스』의 "제자리에 있으려면 온 힘을 다해 달려야 한다"에서 왔다.

**고리가 끊기는 네 가지 방식**

| 끊김 | 무슨 일 | 예시 |
|---|---|---|
| ① 한쪽이 완승 | 상대가 멸종·포기 → 압력 사라짐 | 치타가 너무 강해 가젤 멸종 → 치타도 발전할 이유 없음 |
| ② 빙빙 돎 | 계속 바뀌는데 발전이 아님 | 가위바위보처럼 같은 세 전략을 영원히 돎 (화면에선 성장처럼 보여서 속기 쉬움) |
| ③ 휴전 | "이 정도면 됐다"에서 멈춤 | 각자 다른 구역에 살며 안 마주침 |
| ④ 새로 둘 수가 없음 | 판에서 가능한 수를 다 씀 | 숨바꼭질 6단계 이후 |

**지구는 게임판 자체가 바뀐다 (니치 구성)**
```
시뮬레이션:  [ 고정된 판 ]  안에서 전략 A → B → C → ... → 할 게 없음

지구:        판 1 ──(남세균이 산소를 뿜음)──▶ 판 2: 산소 대기
                                               │ 산소로 큰 에너지를 쓰는 생물이 가능해짐
                                               ▼
                                   판 3: 동물 ──(나무가 생김)──▶ 판 4: 숲, 나무 위 생활
                                                                     │
                                                                     ▼
                                                     판 5: 인간 ──(언어·도시)──▶ 판 6: 문화
```
- 남세균은 살려고 광합성했을 뿐인데 대기가 바뀌었다. 이전 생물 다수에겐 독, 새 생물에겐 기회.
- 비버 댐은 강을 연못으로 바꿔 다른 생물에게 새 서식지를 만든다.
- 사람끼리의 경쟁은 거의 전부 사람이 만든 판(도시, 돈, 인터넷) 위에서 벌어진다.

**지구의 고리는 두 겹이다**
1. 상대가 바뀐다 → 나에게 새 문제 (붉은 여왕) — 시뮬레이션에서 만들 수 있다
2. 판이 바뀐다 → 모두에게 새 게임 (니치 구성) — **어렵다.** 생물이 만든 결과물이 세계 규칙을 바꿀 만큼 세계가 풍부해야 한다. 시뮬레이션은 설계자가 넣은 재료 범위 안에서만 새 판을 만들 수 있고, 재료를 다 쓰면 ④처럼 멈춘다.

**대표님 장치가 막는 끊김**

| 장치 | 막는 끊김 |
|---|---|
| 개체마다 다른 보상 | ③ 휴전, ② 빙빙 돌기 |
| 호르몬으로 보상이 변함 | ③ 휴전 |
| 패턴 기억 대량 저장 | ② 빙빙 돌기 (했던 걸 기억하니 같은 원을 다시 돌 이유가 줄어듦) |
| **흔적이 쌓여 판을 바꾸는 장치 (채택)** | ④ 새로 둘 수 없음 |

흔적 장치 예: 많이 다닌 곳이 길이 되고, 쌓은 물건이 벽이 되고, 그 벽이 다음 세대의 환경이 된다.

### 4-5. 개체별 보상 + 호르몬 (채택)
- 보상이 다르면 원하는 게 달라져서 모두 같은 정답으로 몰리지 않는다. 서로가 서로에게 예측하기 어려운 환경이 된다.
- 호르몬은 보상을 시간에 따라 움직이게 한다. 같은 생물 안에서도 목표가 계속 움직인다.
```
배고픔 ↑  → 음식이 매우 좋음
배부름    → 같은 음식이 시큰둥
스트레스 ↑ → 탐험보다 안전이 좋음
같은 자극 반복 → 무감각해짐 (지루함)
```
- 도파민이 "예상보다 좋았던 정도"에 반응한다는 발견(1997년 무렵)은 강화학습의 핵심 수식(보상 예측 오차)과 거의 같은 모양이다.
- 주의: "밝혀진 걸 다" 넣으면 조절할 값이 수백 개가 되어 무엇이 효과를 냈는지 알 수 없다. **도파민(보상), 배고픔·포만, 스트레스, 습관화, 유대감(옥시토신)**부터 시작해서 하나씩 늘린다.
- 보상 규칙 자체를 진화시키는 연구도 있다 ("어떤 걸 좋아하는 생물이 살아남는가"를 세계가 정함).

## 5. 추가 고려 사항 전체 (★ 없으면 실험이 망가질 수 있음 / ☆ 넣으면 좋음)

### A. 삶의 주기
| | 항목 | 이유 |
|---|---|---|
| ★ | 죽음 | 아무도 안 죽으면 처음 성공한 개체가 영원히 지배한다. 세대가 바뀌어야 새 시도가 들어올 자리가 생긴다 |
| ★ | 번식과 유전 | 뇌·몸 설계도가 자식에게 넘어간다. 평생 학습(빠름)과 세대 진화(느림) 두 속도가 생긴다 |
| ☆ | 짝 고르기 | 생존과 무관한 취향이 형질을 폭주시킨다 (공작 꼬리). 새로움의 두 번째 엔진 |
| ☆ | 어린 시절 | 약하지만 배우는 기간 → 부모의 보호와 가르침이 의미를 가짐 |
| ☆ | 늙음 | 힘은 줄지만 경험 많은 개체 → 지식 전달 역할 |

### B. 몸과 에너지
| | 항목 | 이유 |
|---|---|---|
| ★ | 뇌의 에너지 비용 | 사람 뇌는 몸무게 2%, 에너지 약 20%. 생각이 공짜면 뇌가 무작정 커지거나 균형이 안 생긴다. 똑똑함에 값을 매겨야 "똑똑할 가치가 있는 상황"이 생긴다 |
| ★ | 감각의 한계 | 보이는 범위가 좁고 흐릿해야 한다. 다 보이면 탐험·기억·소통이 필요 없다 |
| ☆ | 몸 형태의 진화 | 다리 개수, 크기, 감각 기관 위치까지 진화 |

### C. 사회와 문화
| | 항목 | 이유 |
|---|---|---|
| ★ | 문화 전달 (가르치기·흉내) | 아마 가장 중요. 사람의 폭발적 발전은 유전자가 아니라 배운 걸 넘기고 그 위에 쌓은 덕이다 (톱니바퀴 효과). 인수인계 현상(1-1)과 같다. 개체는 죽어도 지식은 쌓인다 |
| ★ | 혈연 | 가족을 알아봐야 희생과 협력이 진화한다 |
| ☆ | 평판과 처벌 | 배신자를 기억하고 벌줘야 남남끼리 협력이 유지된다 |
| ☆ | 속임수 | 신호가 있으면 거짓 신호도 생긴다. 막지 않는다. 간파 경쟁이 지능을 밀어 올린다는 가설 |
| ☆ | 남의 마음 읽기 | 직접 넣기보다 생겨나는지 지켜볼 대상 |

### D. 세계
| | 항목 | 이유 |
|---|---|---|
| ★ | 환경 변화와 재난 | 계절, 기후 변화, 가끔 대멸종. 굳은 판을 깨고 빈자리를 만든다 (공룡 → 포유류) |
| ★ | 조합 가능한 재료 | 흔적이 판을 바꾸려면 재료를 섞어 새것을 만들 수 있어야 한다 (돌+나무 → 도구). 지구의 화학 역할. 조합 가능성이 곧 세계의 상한선 |
| ☆ | 지형과 고립 | 산맥·바다로 갈라지면 따로 진화해 다양성 폭발 (섬 효과) |
| ☆ | 병과 기생충 | 붉은 여왕 가설은 원래 기생충 이야기. 다양성과 유성생식을 밀어붙임 |

### E. 마음
| | 항목 | 이유 |
|---|---|---|
| ★ | 잠 (오프라인 정리) | 낮의 경험을 밤에 다시 돌려 패턴으로 묶는 시간. brain의 "밤 정리"와 같다. 대량 패턴 기억에는 압축 시간이 따로 필요하다 |
| ☆ | 놀이 | 어릴 때 대가 없이 시험하는 안전한 탐험 |
| ☆ | 주의력의 한계 | 한 번에 하나만 집중 → 선택이 생긴다 |
| ☆ | 망각 | 용량이 커도 안 쓰는 기억이 흐려지는 장치는 필요하다. 공간이 아니라 관련 있는 걸 빨리 찾기 위해서 |

### F. 실험 운영
| | 항목 | 이유 |
|---|---|---|
| ★ | 정밀도 vs 속도 | 물리를 정밀하게 할수록 느리다. "현실 하루 몇 세대"가 첫 결정 → **하루 10세대로 결정** |
| ★ | 성장 측정 | 변하는 것과 성장하는 것을 구분. **100세대 전 개체와 지금 개체를 붙여 본다.** 지금이 이기면 성장, 비기거나 지면 맴돎 |
| ★ | 저장과 분기 | 세계를 언제든 저장하고, 같은 시점에서 갈라 "재난이 있었다면?" 비교 |
| ★ | 관찰 화면 | 지도 위에 개체·흔적·집단 움직임. 대표님 공간 감각이 가장 크게 쓰일 곳 |
| ☆ | 허점 악용 | 생물은 반드시 물리 엔진 버그를 찾는다 (상자 서핑). 막을지 "자연 법칙"으로 받아들일지 미리 정한다 |
| ☆ | 개입 원칙 | 설계자가 중간에 손대면 결과가 설계자 쪽으로 기운다. 언제 손대도 되는지 미리 정한다 |
| ☆ | 윤리 | 스트레스·고통을 넣고 개체가 복잡해지면 언젠가 생각해야 할 질문. 개인 규모에선 당장 문제 아님 |

### 우선순위 (전부 한 번에 넣으면 무엇이 효과를 냈는지 모름)
```
1단계  세계 + 몸 + 죽음/번식 + 뇌 비용 + 감각 한계          ← 일단 살아 있는 세계
2단계  호르몬 보상 + 연결 기반 호기심 + 잠                   ← 마음
3단계  신호 + 문화 전달 + 혈연                               ← 사회
4단계  흔적·조합 재료 + 재난                                 ← 판이 바뀌는 세계
항상    성장 측정 + 저장/분기 + 관찰 화면
```
단계마다 "100세대 전과 붙이기"로 정체 여부를 재서 어떤 장치가 고리를 살렸는지 하나씩 확인한다.
