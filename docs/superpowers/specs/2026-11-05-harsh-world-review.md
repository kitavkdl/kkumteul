## 1부 구현 마무리 결정 (2026-11-05 서버 세션 18)
1부(확장 칸·갈라 켜기·겨울·부패)는 과제 다섯 → 최종 검토(Critical 0, Important 3) → 고치기 한 번(`ade96fd`) → 고친 부분 재검토(모두 해결, 새로 깨진 것 없음)로 끝났다. 시험 194건 통과, `PINNED_HASH_300` 그대로. 작업 중 내린 결정:
- 실행 방식: 과제마다 구현자 하나 + 검토자 하나(구현 sonnet, 여러 파일 과제는 opus, 검토 sonnet). 대표님 "묻지 말고 끝까지"에 따름.
- 지구 참고값으로 겨울 기초 대사 배수 2.0 → 1.5, 겨울 부패 배수 0.2를 넣음(`docs/research/earth-references.md`).
- 겨울 기본값은 그대로(풀 0.3, 기초 대사 1.5) 두고 0번 목표를 "30~60% 감소"에서 "지구 나쁜 해 범위 55~92% 안 + 무너지지 않음"으로 고침. 저장 없이 30~60%를 맞추려면 겨울 풀이 0.5여야 해 지구값 밖이다. 틀리면 2부 포식자가 겨울 저점(약 250)을 무너뜨릴 수 있고, 그때는 겨울 풀 0.3 → 0.4부터 올린다.
- 부패 시험은 놓인 칸을 `_place_food` 전후 차이로 찾게 조정(커서 위치를 가정하지 않음).
- 최종 검토 지적 전부를 고치기 한 번에 묶음. 설계의 목표 줄은 설계 문서에서 직접 고침.
- 재검토의 범위 밖 관찰(`config.py`의 validate 문구와 `N_EXT_IN` 주석이 아직 없는 암수를 말함)은 그대로 둔다. 확장 칸 13 = 혹독한 세계 9 + 암수 4라는 배정의 근거이고, 암수가 다음 차례다.
