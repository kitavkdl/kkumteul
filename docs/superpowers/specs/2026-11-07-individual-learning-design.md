# 개인 학습이 이득인 세계 — 설계 (둘째 판, 2026-11-07 밤)

사용자 새 방향 1번. "학습이 꺼진 것은 세계가 족보가 통하는 곳이라서일 수 있다(볼드윈 논리). 어느 먹이가 독인지가
한 세대 수명쯤 주기로 바뀌어야 학습이 값을 한다." 이 설계는 그것을 **진화가 배움을 남기느냐 버리느냐**로 가른다.

## 지금 아는 것 (잰 값)
- 독 바뀜: `kernels.good_kind`는 `kind_flip_period` 구간마다 독립 무작위(0/1)라 바뀔 확률이 구간마다 1/2 →
  **평균 바뀜 간격 = 2 × 주기**. 기본 1,500 → 약 3,000스텝.
- 먹이 종류 세계(맛 갈래 바탕 `k4-ctrl` 230만): 평균 나이 약 600(`t-mem-a` 끝 `age_mean` 607), 수명 약 1,030~1,150,
  한 세대 약 700~800스텝, **한 생에 끼니 약 10**(어림, 앞 체인 셈). 끼니 사이 약 100스텝.
- 독 한 알: 먹이 에너지 1.0이 사라지고 0.3을 잃음 → 순 −0.3, 좋은 먹이와 끼당 1.3 차이.
- 기존 평생 학습 규칙 둘은 손 개체로도 가려 먹기를 못 배웠다(결과 문서 네 번째~여섯 번째 시도):
  헤브는 타고난 행동을 지우고, 노드 섭동은 방향을 잡는 데 **백 끼 단위**가 든다.
- 맛 기억(한 끼에 배움, `taste_rate` 0.5)은 기본 주기(1,500)에서 값을 했다: 판정 가 +0.21, 막기 겨루기에서 막은 쪽 6회 모두 전멸.
  다만 대조 b에서 "기억 입력이 들어오기만 해도 생기는 몫" +0.06~0.08이 있었다(결과 문서 "대조 b 가르기").
- 시야는 먹이 종류를 부호(+/−)로 본다. 그래서 **타고난 선호**(+ 쪽으로 가기)도 진화할 수 있다 — 독이 오래 안 바뀌면
  유전자가 따라잡을 길이 있다.

## 정할 것과 결정 (임시 결정, 근거)
### 1. 기존 규칙(헤브·노드 섭동)으로 진화 갈래를 돌리지 않는다
배우는 속도(백 끼 단위)는 독 바뀜 주기와 무관하고, 한 생은 끼니 약 10이다. 주기를 수명에 맞춰도 한 생 안에 배울 수 없으므로
진화가 그 규칙을 남길 까닭이 없다(예측: 학습률 유전자 그대로 내려감). 손 개체 결과가 이미 이 한계를 잰 값이라
갈래를 돌려 "꺼짐"을 한 번 더 보는 것은 정보가 적다. **볼드윈 논리를 가르려면 한 생 안에 배울 수 있는 규칙이 필요하다** →
맛 기억이 그 규칙이다. (사용자 확인 ②: "손 개체로 배울 수 있는 규칙인지 먼저" — 헤브·섭동은 아니고, 맛 기억은 판정 0에서 가능함을 보였다.)
틀렸을 때 비용: 기존 규칙이 다른 세계에서 살아날 가능성을 안 본 것. 시간이 남으면 주기 500 갈래 하나를 단서로 돌린다(판정 아님).

### 2. 새 장치: 맛 배움 속도 유전자 (`taste_gene_enabled`, 기본 꺼짐)
지금 맛 기억의 배움 속도는 설정값 하나(`taste_rate`)라 진화가 배움을 끌 수 없다. 볼드윈 질문("세계가 바뀌지 않으면 진화가 배움을 버리나")을
보려면 **진화가 배움을 줄이고 늘릴 수 있어야** 하고, 배움에 **값**이 붙어야 한다(공짜면 쓸모가 없어도 떠돌 뿐).
- 개체마다 저장 유전자 `taste_g`(float32). **실제 배움 속도 = clamp(taste_rate + taste_g, 0, 1)**.
  `taste_g`는 설정값에서 벗어난 몫이다. 처음 개체·옛 체크포인트·장치 꺼짐에서 0 → 배움 속도는 `taste_rate` 그대로.
  그래서 장치를 끄면 옛 동작·옛 해시와 똑같고(HASH_DEFAULTS에 0으로 더함), 옛 체크포인트에서 켜도 모두 `taste_rate`에서 출발한다.
- 변이: 자연 출생 때 `taste_g += taste_gene_sigma × N(0,1)`(선형), 실제 속도가 [0, 1] 안에 들게 `taste_g`를
  [−taste_rate, 1 − taste_rate]로 자른다. **선형**으로 하는 까닭: 기존 학습률 `eta`는 곱(로그 눈금) 변이라 작아지면 빠져나오기 어렵다.
  0 근처가 덫이면 세계를 바꿔도 공정한 판정이 안 된다(insight 지적). 난수는 **새 용도 번호 `S_TASTE_GENE = 31`**(rng.py 맨 뒤에 덧붙임,
  카운터식이라 옛 흐름 그대로)에서 (자식 id, 0)으로 뽑는다. ~~재주입·대조 새끼(`_reset_body`)는 0.~~ → 둘째 판에서 정정: 유전체라 부모가 있는 모든 출생(재주입·대조 포함)에서 베끼고 변이한다. 0은 처음 개체·`add_random_agent`(무작위 유전체)뿐.
  임시 `taste_gene_sigma` 0.02: 30만 스텝(약 400세대)이면 떠돌기만으로 약 0.4 퍼진다 — 움직일 수 있는 크기.
- 비용: 산 개체마다 스텝당 `taste_cost × 실제 속도`를 에너지에서 뺀다(장부 `L_BRAIN` — 배움은 뇌의 값). 장치가 꺼져 있으면 0.
  임시 `taste_cost` 0.0005: 속도 0.5면 스텝당 0.00025, 한 생(약 1,100) 약 0.28 — 끼니 한 번의 4분의 1쯤, 기초 대사(0.003)의 약 8%.
  `plast_cost` 0.002(최대)와 같은 크기대. 이 값이면 배움이 쓸모없을 때 진화가 줄일 만큼 아프고, 쓸모 있을 때 이득(끼당 1.3)보다 훨씬 작다.
- **첫걸음 기울기**: 속도는 연속이라 조금 빨라질 때마다 조금 더 맞게 기억한다(문턱 없음). 기억을 읽는 배선도 같이 진화해야 하는 점은
  맛 기억 갈래에서 30만 스텝 안에 찾았다(판정 가).
- 켜려면 `preset=taste`가 필요하다(맛 기억이 켜져 있어야 뜻이 있음). `taste_gene_enabled`인데 `taste_enabled`가 아니면 설정 오류.
- 기록: `stats.jsonl`에 산 개체의 실제 배움 속도 평균 `taste_rate_mean`(장치 켬일 때만). **추세는 판정이 아니라 단서.**

### 3. 주기 넷 (설정만)
| 갈래 | `kind_flip_period` | 평균 바뀜 간격 | 한 생에 견주어 | 예측 |
|---|---|---|---|---|
| 빠름 | 50 | 약 100스텝 | 끼니 한 번마다 바뀜 | 배운 것이 다음 끼에 맞을 확률 약 1/2 → 배움 값 없음 |
| 수명쯤 | 500 | 약 1,000 | 한 생에 약 한 번 | 배움 값 가장 큼(Stephens 1991, 리서치 raw §1-1) |
| 길게 | 15,000 | 약 30,000 | 약 40세대 | 타고난 선호가 일부 따라잡음 → 배움 값 줄어듦 |
| 고정 | 1,000,000,000 | 바뀌지 않음 | — | 타고난 선호로 충분 → 배움 값 0, 진화가 속도를 깎음 |
(기본 1,500 = 간격 3,000은 앞 맛 갈래 결과가 있어 비교 기준으로 쓰고 새로 돌리지 않는다.)
※ insight의 공간 모자이크 + 출생 분산 제안(시간 대신 공간으로 바뀜)은 이 결과 뒤 후보로 둔다 — 한 끼에 배우는 규칙은 생애 중간 반전도 다음 끼에 다시 배우므로 시간 주기가 먼저 뜻이 있다.

### 4. insight 추천 반영
- 대조 b에서 본 "입력만 있어도 생기는 몫" 때문에 0으로 막기는 천장을 부풀릴 수 있다 → **막기 겨루기를 0 막기와 섞기 막기(`--mode shuffle`) 둘 다**.
  섞기로 막아도 지면 "어느 쪽이 독인지라는 내용"이 값을 하는 것이다(insight 11/06 20:2x).
- "정보 값의 천장" 손 개체(정답을 아는 개체 대 아무거나)는 따로 돌리지 않는다: 맛 세계에서 막은 쪽이 6회 모두 전멸하고,
  손 개체 "그대로" 세계에서 맛 끈 무리가 굶어 사라져 천장이 크다는 잰 값이 이미 있다(insight도 동의).
- 1인당 섭취량·먹은 것의 독 여부 기록: 판정이 겨루기라 이번에는 넣지 않는다(`n_meal`·`n_poison` 계수는 이미 있어 필요하면 나중에).

## 판정 (실행 전에 정함, 바꾸지 않는다)
바탕 `k4-ctrl` 230만(앞 맛 갈래와 같은 바탕). 갈래마다 `preset=taste taste_gene_enabled=true kind_flip_period=<주기>`, 30만 스텝, 씨앗 a.
시간이 되면 씨앗 b. 각 갈래 끝에서:
- **가 (쓰임)**: `knockout split --channel taste`(0 막기)와 `--mode shuffle`(섞기 막기), 400마리씩 8,000스텝 6회 + 중립.
  막은 쪽이 지면(대조 규칙 포함 판정이 "쓴다") 그 주기에서 배움이 값을 한다.
- **나 (진화가 배움을 남겼나)**: 같은 끝 생물로 두 벌 — 원래 대 배움 속도를 0으로 한 벌(`taste_g` = −taste_rate) 겨루기.
  0으로 한 쪽이 지면 진화가 남긴 배움이 값을 한다. 도구가 필요하면 `knockout`에 맛 속도 막기 방식을 더한다(구현 계획에서).
  ※ 가와 나는 거의 같은 것을 다른 길로 잰다(가: 입력을 막음, 나: 기억이 안 바뀌게 함). 나는 대조 b의 "입력만 있어도" 몫이 없다(기억 0이면 물든 시야 0).
- **볼드윈 판정**: 수명쯤(500)에서 가·나가 "쓴다"이고 **고정에서 가를 수 없음**이면 "학습은 세계가 바뀔 때만 남는다"를 지지.
  고정에서도 쓰이면(타고난 선호 대신 배움으로 가려 먹음) 볼드윈 논리의 "유전자가 따라잡음"은 30만 스텝 안에 안 일어난 것.
  빠름(50)에서 쓰이면 예측이 틀린 것 — 기억이 아닌 다른 몫(입력 효과)을 의심한다.
- 단서(판정 아님): 끝 `taste_rate_mean`, 무리 크기.

## 끄고 켜기·안전
- 기본 꺼짐. 꺼져 있으면 `taste_g`는 0으로 남고 비용 0, 해시는 HASH_DEFAULTS로 옛 값과 같다(박은 해시 값 시험이 그대로 통과해야 한다).
- 에너지: 비용은 에너지를 빼기만 하고 장부 `L_BRAIN`에 더한다 — 장부 시험에 장치 켬 경우를 더하고, 장부에 안 더하면 실패하는지 본다.
- rng: 새 용도 31만 덧붙임. 기존 호출 순서 바뀌지 않음.
- 체크포인트: 새 저장 필드. 옛 체크포인트를 읽으면 0.

## 고칠 파일 (어림)
`config.py`(설정 셋·검사·preset 없음), `kernels.py`(필드·pack·eat·copy_genome·_reset_body), `rng.py`(용도 31), `run.py` 또는 stats 쓰는 곳(`taste_rate_mean`),
`knockout.py`(나 판정용 방식, 필요하면), 시험. 파일 셋 이상 → 맥락 없는 검토 둘(규칙 축·명세 축).

## 둘째 판 — 맥락 없는 검토 두 갈래(sonnet) 반영 (위 내용보다 이 절이 앞선다)
### 명세 축 (시킨 대로인가)
1. [치명] 고정 갈래 "가를 수 없음"은 볼드윈(타고난 선호가 따라잡음)과 배선 퇴화를 못 가른다 → **반영**: 갈래 끝마다
   독 비율(`taste_gene_judge.py observe`, 3,000스텝 더 돌려 먹힌 알 가운데 독)을 판정 지표에 넣는다.
   "가 0 + 독 비율 낮음" = 타고난 선호가 따라잡음(볼드윈 지지), "가 0 + 독 비율 약 0.5" = 배움도 선호도 없음(따로 적음).
2. [치명] 계획 1순위(기존 평생 학습 규칙이 살아남나)를 안 돌린다 → **반영**: 주기 500, 맛 끔, 기존 헤브(`mind_enabled`, eta 진화,
   `plast_cost`) 갈래 하나 + 끝 무리 원래 대 eta=0 겨루기(`rate-zero --gene eta`). 맛 기억을 주 대상으로 둔 까닭(위 1절)은 결과 문서에도 적는다.
   순서는 맛 주기 갈래 뒤(시간이 모자라면 인수인계에 남김).
3. [중요] 씨앗 a·b 둘을 판정 필수로 → **반영**(판정 문장은 두 씨앗이 같은 쪽일 때만 "지지"). 중립·min_detectable은 split에 이미 있음.
4. [중요] 기본 1,500도 같은 장치로 → **반영**. 갈래: 50 / 500 / 1,500 / 15,000 / 고정(1,000,000,000).
5. [중요] 첫걸음: 속도 0 근처에서도 조금 배우면 이득인가 → **반영**: 주기 500에서 `taste_rate=0.05`로 시작하는 갈래
   (유전자 범위가 [−0.05, 0.95]라 오를 수 있다). 손 개체 변형(hand_learner taste 속도 0.05·0.1 대 0)은 시간이 남으면.
6. [사소] "수명쯤" 정의 둘 — 평균 바뀜 간격 2×주기(500 → 1,000 ≈ 수명 1,100) / 상관이 사라지는 시간 ≈ 주기(500 ≈ 반 생애). 둘 다 적는다.
### 규칙 축 (레포 규칙·코드 냄새)
1. [치명] `measure.GENOME`에 `taste_g` → **반영**. 옛 생물 묶음(pack)에 없으면 0으로 읽는다(`pack.read`).
2. [치명] 맛 막기 대조 규칙(`knockout.OFF_RULES` taste·taste_vis·taste_val)이 `taste_enabled=false`만 주면 유전자 켠 세계에서 설정 검사에 걸린다
   → **반영**: `taste_gene_enabled=false`도 같이. `taste_judge.py flip-diff`의 끔 쪽도 같이(`with_overrides`는 한꺼번에 적용한 뒤 검사).
3. [중요] 재주입·대조 새끼의 유전자 → **반영**: 위 정정(모든 출생에서 베낌).
4. 1,500 갈래 → 명세 4와 같음.
5. [중요] 나 판정에서 속도 0 쪽은 비용을 안 낸다 → **반영(문서)**: 0 쪽에 유리한 치우침이라, 0 쪽이 지면 보수적인 결론.
   변이로 다시 오를 걱정은 없다 — 겨루기 세계는 `mutation_enabled=false`라 taste_g가 그대로 물려진다(`measure.arena_config`).
6. [사소] `taste_rate_mean`은 `world.summary`의 맛 블록에, 체크포인트 코드는 안 고침(새 필드는 AGENT_FIELDS 저장 필드라 자동),
   설정으로 장치를 꺼도 taste_g는 지우지 않음(유전체), 고정 주기는 정수 1,000,000,000.
### 구현에서 정한 것
- 비용은 `eat`의 잊기 자리에서 뺀다(산 개체 스텝마다 한 번, 배부른 개체도). 맛 블록이 실제로 쓰일 때만(`Q_TASTE_GENE`).
- 시험(`tests/test_taste_gene.py`): 비용은 `eat`만 직접 불러 잰다 — 세계를 돌리면 에너지(감각 입력)가 달라져 이동 비용이 갈라진다.
