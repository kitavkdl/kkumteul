# 2~4단계 장치 (2026-11-05 새벽에 넣음)

1단계가 돌고 나서 한 번에 넣은 장치들이다. **전부 Claude가 정한 임시 결정이고, 기본은 꺼져 있다.**
켜는 법: `--set preset=stage2`(마음) / `stage3`(마음+사회) / `stage4`(마음+사회+판이 바뀌는 세계). 하나씩 켜려면 `mind_enabled`, `social_enabled`, `niche_enabled`.
1단계 세계의 체크포인트에서 갈라 켤 수 있다(`run branch --from ... --set preset=stage2`). 장치의 효과는 그렇게 같은 시점에서 가른 두 세계를 견주어 본다.

여기 있는 것은 "장치"다. 생물이 그것을 쓰게 되는지, 그래서 무엇이 생기는지는 아직 재지 않았다. 아래 "확인된 것"을 본다.

## 2단계: 마음 (`mind_enabled`)
| 장치 | 어떻게 | 설계 노트 |
|---|---|---|
| 호르몬 | 개체마다 허기·스트레스·도파민·지루함 네 값이 천천히 움직인다. 스트레스·도파민·지루함·피로가 뇌 입력으로 들어간다 | 4-5 |
| 개체마다 다른 보상 | 보상 = 유전되는 가중치 8개 × (먹음, 에너지 변화, 닿음, 호기심, 허기×먹음, 스트레스, 이웃이 먹음, 상수). 허기가 크면 같은 먹이의 값이 달라진다 | 4-5 |
| 도파민 | 학습 조절 신호 = tanh(보상 − 기대 보상). 기대는 최근 보상을 따라간다 | 4-5 |
| 평생 학습 | 쓰는 가중치 = 타고난 것 + (뉴런별 가소성 유전자) × (살면서 배운 것). 배운 것은 "방금의 활동 짝 × 조절 신호 × 학습률"로 바뀐다. 자식에게 물려주지 않는다 | 0-3, 5-A |
| 연결 기반 호기심 | 시야를 패턴 8개 중 가장 가까운 것에 묶고(원본을 다 저장하지 않음), 지난 패턴→이번 패턴의 연결이 새로울수록 호기심 값이 크다. 잡음은 연결이 금방 차서 값이 사라진다 | 4-3 |
| 습관화 | 같은 연결을 되풀이하면 호기심이 줄고 지루함 호르몬이 오른다 | 4-3 |
| 잠 | 깨어 있으면 피로가 쌓이고 피로할수록 덜 배운다. 잠 출력을 내거나 피로가 가득 차면 잠든다. 자는 동안 못 보고 못 움직이고, 기초 대사가 줄고, 약한 학습 흔적이 지워진다 | 5-E |
| 비용 | 학습률에 비례한 학습 비용을 낸다 | 5-B |

## 3단계: 사회 (`social_enabled`)
| 장치 | 어떻게 | 설계 노트 |
|---|---|---|
| 신호 | 출력 2개가 신호가 된다. 듣는 거리 안 이웃의 신호를 앞·뒤로 나눠 듣는다(입력 4개). 뜻은 주지 않는다. 내는 데 비용이 든다 | 0-4 |
| 혈연 | 가장 가까운 이웃의 색 유전자가 나와 닮은 정도가 입력으로 들어간다. 색은 유전되고 조금씩 변한다 | 5-C |
| 이웃이 먹는 것 보기 | 가까운 이웃이 방금 먹었는지가 입력이자 보상 특징이다(남을 보고 배울 실마리) | 5-C |
| 주기 | 주기 출력이 켜져 있으면 닿아 있는 가장 가까운 이웃에게 에너지를 건넨다(10%는 사라짐) | 5-C |

속임수는 막지 않는다. 처벌·평판 장치는 넣지 않았다(생기는지 볼 대상).

## 4단계: 판이 바뀌는 세계 (`niche_enabled`)
| 장치 | 어떻게 | 설계 노트 |
|---|---|---|
| 길 | 지나간 칸에 흔적이 남고 천천히 흐려진다. 흔적이 쌓인 칸에서는 이동 비용이 준다. 내 자리와 왼쪽 앞·오른쪽 앞의 흔적을 느낀다 | 4-4 |
| 거름 | 쌓기 출력으로 자기 에너지를 그 칸의 땅에 넣는다. 세계 먹이 유입의 일부가 거름 있는 칸에 난다(유입의 합은 그대로) | 4-4, 5-D |
| 조합 | 거름과 닦인 길이 함께 있는 칸에 먹이가 더 잘 난다 | 5-D |
| 재난·기후 | 각본 파일로 준다(`scenarios/`) | 5-D |

## 확인된 것과 아닌 것
- 확인(시험): 세 단계 모두 켠 채로 세계가 재주입 없이 돌고, 에너지 장부가 맞고, 같은 씨앗이면 같은 세계가 나온다. 장치를 끈 채로는 1단계 세계가 달라지지 않는다. 1단계 체크포인트에서 갈라 켤 수 있다.
- 확인 안 됨: 생물이 학습·신호·주기·거름을 **쓰도록 진화하는지**, 켠 세계의 생물이 끈 세계의 생물보다 나은지. 결과가 나오면 `wayfinder/`에 적는다.
- 알려진 약점: 마음을 켜면 뇌 계산이 2~3배 느려진다(맥에서 초당 약 400스텝). 처음 개체는 주기·쌓기 출력이 무작위라 처음에는 에너지를 헛되이 건네고 쌓는다.
