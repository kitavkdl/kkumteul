# 관찰 화면 시제품
종류: 시제품
상태: 시제품 있음 (2026-11-04, 대표님이 보고 정할 차례)
막힘: 없음

## 질문
관찰 화면에 무엇이 어떻게 보여야 하나? (세계 지도, 개체, 개체 하나 들여다보기, 시간 돌려 보기, 집단 숫자, 폰에서 보기)
가짜 데이터로 움직이는 화면을 대충 만들어 놓고 대표님과 보면서 정한다. 만든 것은 `proto/`에 두고 버린다.

## 답
시제품을 실제 데이터로 만들었다: `kkumteul/viewer.py`, `viewer.html`. `python3 -m kkumteul.viewer --runs runs`.
- 지금 되는 것: 세계 지도(끌기·확대, 폰 두 손가락 확대), 개체 색 바꾸기(계통·에너지·세대·뇌 크기·나이), 개체 하나 고르기(번호·세대·나이·에너지·뉴런·자식 수, 시야 부채꼴, 따라가기), 시간 막대로 돌려 보기, 재생, 실시간, 집단 숫자 차트 4장(개체 수·먹이·평균 세대·평균 뉴런)과 표, 실행 고르기(분기·대조 실행 포함).
- 세계가 빨라서(한 개체의 일생이 현실 1초쯤) 실시간 화면으로는 개체 하나를 따라갈 수 없다. 그래서 20만 스텝마다 400스텝을 한 스텝씩 녹화하고("촘촘한 구간"), 화면의 "촘촘히 녹화" 단추로 지금부터 600스텝 녹화를 요청할 수 있다.
- 아직 없는 것: 뇌 들여다보기(가중치·활성), 계통 나무, 한 개체의 일생 다시 보기, 두 실행 나란히 보기.
- **대표님이 직접 보고 무엇이 더 보여야 하는지 정하는 일이 남았다.**
