## 겨루기 (`measure assay`)
한쪽 400개체, 8,000스텝, 변이 끔. r은 1,000스텝당 ln(지금 쪽 수 ÷ 옛 쪽 수)의 기울기.

| 옛것 | 지금 | r | 같은 무리끼리(평균, 표준편차) | 결과 |
|---|---|---|---|---|
| 0스텝(0세대) | 80만 스텝 | +5.59 ± 0.54 (6회) | −0.04, 0.07 | 옛것 6회 모두 전멸 |
| 40만 스텝 | 80만 스텝 | +0.36 ± 0.02 (6회) | +0.01, 0.03 | 지금이 이김(끝 개체 수 약 55~118 대 1,190~1,250) |
| 60만 스텝 | 80만 스텝 | +0.20 ± 0.01 (6회) | +0.02, 0.02 | 지금이 이김(약 160~260 대 1,020~1,130) |
| 대조 실행 10만 스텝 | 본 실행 10만 스텝 | +2.78 ± 0.37 (4회) | −0.16, 0.26 | 대조 4회 모두 전멸 |

한쪽이 전멸한 판은 r의 크기에 뜻이 없다. "전멸"만 읽는다.

## 다섯 시점 모든 쌍 (`measure ladder`, 4회씩)
행 = 옛것, 열 = 새것, 값 = r. *는 t 검정(95%)을 넘은 칸.

| | 30만 | 50만 | 60만 | 80만 |
|---|---|---|---|---|
| 10만 | +1.06* | +0.86 | +0.40 | +0.85* |
| 30만 | | +0.04 | +0.10 | +0.27* |
| 50만 | | | +0.09* | +0.30* |
| 60만 | | | | +0.20* |

- 10칸 모두 새것 쪽이 양수이고 6칸이 검정을 넘었다. 등급과 시간의 순위 상관은 +0.60, 추이 성분 비율은 0.91(순수 잡음이면 0.40쯤).
- 30만·50만·60만 사이는 차이가 작아 가르지 못한 칸이 있다. 10만과 겨룬 칸은 반복 사이 흔들림이 컸다(표준오차 0.15~0.30).
- 읽기: 순환이 아니라 누적 쪽이다. 다만 중간 구간의 진보는 이 측정의 잡음에 가깝다.

## 눈에 띈 것
- 평균 속도가 0.6에서 0.25 근처로 줄고 뇌도 줄었다. 진화한 것은 새 행동이 아니라 절약이다. 원인을 따로 확인하지는 않았다.
- 대조 실행에서는 먹이가 상한까지 쌓였다(본 실행은 300 안팎).
- 화면에서 먹이 자리마다 색(계통)이 다른 무리가 모여 있다.
- 이 실행의 디스크: 사건 기록 59MB, 프레임 147MB, 체크포인트 658MB(10만 스텝마다 9개를 남긴 설정).
