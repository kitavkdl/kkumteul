# JaxLife 읽기
종류: 조사
상태: 닫힘 (2026-11-04)
막힘: 없음

## 질문
JaxLife는 세계·몸·감각·뇌·죽음/번식·측정·저장을 어떻게 만들었나? 우리 1단계의 바탕으로 쓸 수 있나, 설계만 빌릴 것은 무엇인가?
(GPU 없음, Python+numpy 결정, 라이선스 기준으로 본다.)

## 답
바탕으로 쓸 수 없다. 레포에 LICENSE 파일이 없어서(GitHub API도 `license: null`) 코드를 복사·수정해 공개 레포에 올릴 수 없고, 전부 JAX+flax라 "numpy 직접 구현" 결정과도 맞지 않는다.
우리 1단계의 핵심이 여기에는 없다. 질량·속도·마찰·충돌이 없고, 뇌 크기·계산에 에너지 비용이 없고, 감각에 거리 한계가 없다. 세대·혈통 기록, 저장한 것을 다시 읽는 코드, 과거 개체와 붙여 보는 측정도 없다.
빌릴 설계: 고정 크기 배열 + 생존 표시, 개체 수가 많을수록 비싸지는 번식 비용, 나이 들수록 오르는 생존비, 원래대로 돌아가는 속도가 다른 여러 겹의 지형 값, 난수 상태를 세계 상태 안에 넣기, 디버그용 뇌(영/무작위).
논문의 "통신·농업·도구 사용"은 근거가 약하다. A100 GPU 1대로 65,536스텝(개체 128)을 돌린 결과이고 속도·시드 수는 보고하지 않았다. 코드에 번식 때 부모 번호가 어긋나 보이는 곳이 있다(읽기로만 확인, 실행하지 않음).
확인하지 못한 것: 초당 스텝·램, CPU만으로 돌렸을 때의 속도.
