# 신호, 혈연, 이웃 보기, 주기 (3단계 사회)
종류: 문답
상태: 임시 결정 (2026-11-05, 대표님 확인 전)
막힘: 없음

## 질문
언어는 주지 않고 소통의 재료만 줄 때 무엇을 주나? 서로 돕는 행동의 재료는? 속임수와 처벌은?

## 답
- 정한 것(`social_enabled`, 묶음 `stage3`)
  - 신호: 출력 2개. 듣는 거리(`hear_range` 24) 안 이웃의 신호를 앞·뒤로 나눠 듣는다(입력 4개). 뜻은 주지 않는다. 비용 = `signal_cost` 0.0005 × (|신호1| + |신호2|).
  - 혈연: 가장 가까운 이웃의 색 유전자가 나와 닮은 정도가 입력이다. 색은 유전되고 `color_sigma` 0.02씩 변한다.
  - 이웃이 먹는 것 보기: 가까운 이웃이 방금 먹었는지가 입력이자 보상 특징이다.
  - 주기: 주기 출력이 켜져 있으면 닿은 가장 가까운 이웃에게 스텝당 `give_rate` 0.02를 건넨다. `give_loss` 0.1은 사라지고, 에너지가 `give_min_energy` 1.0 아래면 주지 못한다.
  - 처음 개체는 주기·쌓기·공격 출력 편향을 −1로 둔다(안 하는 쪽).
  - 속임수는 막지 않고 처벌·평판 장치는 넣지 않았다(생기는지 볼 대상).
- 까닭: 설계 노트 0-4, 5-C. 문화 전달은 가장 중요하다고 했으나 가르치기·흉내 장치는 넣지 않았고, 남을 보고 배울 실마리로 "이웃이 먹는 것"만 두었다.
- 임시 결정이다.
- 확인한 것
  - 에너지가 새거나 생기는 길이 없다. 주고받기 고리는 순손실이다(`code-review-2026-11-05.md` "맞다고 확인된 것").
  - 첫 측정(`results.md` "유전자로 본 것", 110만 스텝, 대조 / 사회 / 판): **주기는 진화가 줄였다**(주기 출력 편향 +0.08 / −0.44 / −0.39, 건넨 횟수 스텝당 약 78회 → 22회).
    듣기 입력 가중치 0.28 / 0.28 / 0.24, 혈연·이웃 입력 0.34·0.36 / 0.33·0.33 / 0.25·0.24는 쓰이지 않는 가중치가 떠다니는 수준(0.25~0.35)이다. 신호 세기는 사회 0.30 → 0.28, 판 0.30 → 0.34로 변화 없음.
  - 코드 검토가 6만 스텝 두 판에서 본 신호 세기 상승(0.08 → 0.34, 0.10 → 0.18)도 기능은 확인되지 않았다.

## 남은 것
- 신호가 뜻을 갖는지, 주기가 혈연에게 몰리는지는 증거가 없다. 이 세계에는 신호를 들어서 이득을 볼 상황이 없다는 것이 추정이다. "그 장치가 있어야 사는 압력"이 필요하다(설계 노트 3-4).
- 신호와 혈연이 값을 하게 할 협력 먹이(곁에 다른 개체가 있어야 먹는 큰 먹이)는 쓰다 만 가지가 있고 `main`에 없다(`sessions/tasks.md`). 넣을지는 정하지 않았다.
- 이 단계의 소통을 "규범·가르침"으로 읽을 지표는 없다. 5단계 제안은 [map.md](map.md)의 물음 참고.
