# 노드 섭동 학습 규칙
종류: 문답
상태: 임시 결정 (2026-11-05, 사용자 확인 전). 판정: 이 과제에는 너무 느리다
막힘: 없음

## 질문
보상으로 조절하는 헤브 학습은 손으로 만든 개체도 가려 먹기를 못 배운다([T22](T22-lifelong-learning.md)). 학습 규칙을 무엇으로 바꾸면 되나?

## 답
- 정한 것: `perturb_sigma`(기본 0 = 헤브 학습 그대로). 0보다 크면 은닉 뉴런이 **추력·회전 출력으로** 보내는 값을 그 크기의 잡음으로 흔들고, 보상이 오면 흔든 쪽으로 배운다. 가중치를 고치는 식(학습률 × 보상 신호 × 입력 흔적 × 출력 흔적)은 그대로다.
  - 흔적은 연결마다 "그 순간 들어온 값 × 흔든 양"을 쌓는다(`elig_in`, `elig_rec`). 쌓는 값은 잡음 × 기울기(1 − c²)라 평균이 0이다.
  - 잠·번식·신호 출력, 자는 동안, 되먹임으로 남는 은닉 상태는 흔들지 않는다. α가 음수인 뉴런은 부호를 뒤집어 쌓는다. 난수 용도 18.
  - 켜면 연결별 흔적 배열만큼 메모리와 체크포인트가 커진다(평생 학습 배열과 같은 크기).
- 까닭: 흔든 양의 평균이 0이라 헤브 학습의 반동(먹은 뒤 기대 보상이 내려오는 동안의 음수 신호)이 평균으로 사라지고, 출력이 0이어도 흔든 만큼 학습이 일어나 0을 넘는다(Fiete & Seung 2006류, `results.md` "네 번째 시도").
- 임시 결정이다. `perturb_sigma`는 단계 묶음(`preset`)에 넣지 않았다.
- 확인한 것
  - 설계 검토(`perturb-design-review.md`) 치명 3건(α 부호, 포화한 뉴런의 흔적, 잡음 섞인 은닉 상태의 편향)을 구현 전에 반영했고, 둘째 판의 규칙 축 치명 1건(흔적 배열이 작으면 커널이 배열 밖에 조용히 쓰는 것)도 막았다. `perturb_sigma=0`이면 옛 코드와 상태 해시가 같다(여섯 설정, 800스텝).
  - 첫 판(흔적 둘의 곱)은 타고난 취향 없는 개체가 **거꾸로** 배웠고(뒤집힘 −0.25), 연결별 흔적으로 고쳐 거꾸로 배우지는 않게 됐다(`results.md` "다섯 번째 시도").
  - 학습 규칙만 재는 세계(대사 비용 0, 번식 끔)에서 신호는 있으나 너무 약하다: 기울기는 옳은 쪽 +0.07~+0.13인데 12,000스텝에 서른~마흔 끼를 먹고도 독 비율은 0.49~0.51에서 안 움직인다. 안 배우는 개체는 6,000스텝에 77끼, 배우는 개체는 23~31끼로 덜 먹는다. 재료(기대 보상, 흔적 길이, σ 0.1·0.2·0.3)를 바꿔도 같다("여섯 번째 시도의 결과").

## 남은 것
- 방향은 맞지만 백 배쯤 느리다(한 구간 5~15끼, 방향을 잡으려면 백 끼 단위). 장치는 기본 꺼짐으로 남겨 둔다. 환경이 한 세대보다 훨씬 천천히 바뀌는 과제에서는 쓸모가 있을 수 있다.
- 겨루기와 세계 갈래는 "배우게 되면" 하기로 했던 것이라 하지 않았다.
- 켠 세계의 계산 속도는 재지 않았다(`bench`, 검토 규칙 축 4번 보류).
